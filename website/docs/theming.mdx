# Theming

Forma components work without a global stylesheet. The optional base CSS gives
an application a small shared token layer while component tokens provide precise
local control.

```ts
import 'forma/css/base.css';
```

## Global tokens

| Token | Default | Purpose |
| --- | --- | --- |
| `--forma-color-primary` | `#0d6efd` fallback | Base color for neutral components |
| `--forma-color-primary-hover` | Derived from primary | Neutral hover color |
| `--forma-color-primary-active` | Derived from primary | Neutral pressed color |
| `--forma-color-focus` | `#2563eb` | Shared keyboard focus color |
| `--forma-font-family` | System font stack | Shared application font |
| `--forma-radius-medium` | `0.375rem` | Shared medium corner radius |

```css
:root {
  --forma-color-primary: #6d28d9;
  --forma-color-focus: #7c3aed;
  --forma-radius-medium: 0.625rem;
}
```

## Button tokens

| Token | Purpose |
| --- | --- |
| `--forma-button-background` | Resting background |
| `--forma-button-background-hover` | Hover background |
| `--forma-button-background-active` | Pressed background |
| `--forma-button-color` | Label color |
| `--forma-button-border-color` | Border color |
| `--forma-button-border-radius` | Corner radius |
| `--forma-button-focus-color` | Keyboard focus ring |
| `--forma-button-font-weight` | Label weight |
| `--forma-button-gap` | Gap between slotted contents |
| `--forma-button-min-height` | Minimum control height |
| `--forma-button-padding-block` | Vertical padding |
| `--forma-button-padding-inline` | Horizontal padding |
| `--forma-button-disabled-opacity` | Disabled opacity |

Tokens can be applied globally or to one component subtree:

```html
<div
  style="
    --forma-button-border-radius: 999px;
    --forma-button-font-weight: 700;
  "
>
  <forma-button>Rounded button</forma-button>
</div>
```

## Properties and tokens

The `color` and `textColor` properties are convenient per-instance palette
controls. Explicit `--forma-button-*` tokens take precedence when both systems
target the same visual value. Invalid colors and unresolved CSS variables fall
back to the active variant palette.

```html
<div style="--brand-color: hsl(262 52% 55%)">
  <forma-button variant="cute" color="var(--brand-color)">
    Branded button
  </forma-button>
</div>
```

## Legacy fallbacks

`--forma-color-accent`, `--forma-color-accent-hover`, and
`--forma-color-accent-active` remain supported as fallbacks. New applications
should use the corresponding `--forma-color-primary*` tokens.
