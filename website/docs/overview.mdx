# Forma

Forma is a framework-agnostic UI library built with Stencil. It provides
standards-based Web Components, generated React and Vue wrappers, optional base
CSS, and one consistent component API.

## One component library, three ways to use it

| Approach | What it provides |
| --- | --- |
| Web Components | Native custom elements for HTML or any JavaScript application |
| React | Typed wrappers with idiomatic React properties |
| Vue | Generated Vue 3 wrappers without a global plugin |

## What Forma provides

- Browser-native interaction and accessibility behavior
- Self-contained component styles with optional shared tokens
- Tree-shaken component registration or an aggregate loader
- Generated TypeScript types, React wrappers, and Vue wrappers
- Source-generated component API documentation
