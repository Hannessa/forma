
# General Guidelines

- Always read the README.md file before making changes to understand the project.
- Always keep the README.md file up-to-date as a general overview and documentation.
- When writing code, always follow the coding guidelines below.

# Coding Guidelines

- Adhere to KISS (Keep It Simple, Stupid) principles: Write short, clear and straightforward code that is easy to read and understand, and avoid unnecessary complexity.
- Avoid adding redundant helper functions or additional layers of abstractions unless it clearly avoids code duplication and makes the code shorter.
- Always comment your code by adding short one-line comments regularly throughout the code to break it up into readable chunks. For example, add comments before functions, loops, conditionals and data transformations to summarize what they do. Use comments liberally, and even more so in complex sections.
- Never add any tests unless requested.
- Never run any build steps unless requested.
- Never run it in the browser unless requested.
